# Wild Scope: Sniper Hunter

Modern first-person hunting game (Three.js + Vite). Static build, relative paths, runs from any folder / GitHub Pages / CrazyGames.

- Entry: `index.html` (CrazyGames SDK v3 loaded from sdk.crazygames.com; game runs without it)
- 3D models: `models/*.glb` (Tencent Hunyuan3D `/shape_generation`, locally colored, decimated, rigged at runtime)
- Controls: touch — drag to look, SHOOT, SCOPE, RELOAD, SWITCH. PC — mouse look (click to lock), left click shoot, right click / Space scope, R reload, Q / 1-4 switch, Esc pause.
